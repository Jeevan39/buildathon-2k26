# Buildathon 2K26

> A creative vibe-coding project inspired by Buildathon 2.0 – 2K26.

A modern, responsive event website created as an experimental web-development project. The project was built to explore modern frontend development, UI design, responsive layouts, backend integration, and database-driven functionality.

This is a personal/experimental project and is not intended to represent the official website of the event or institution.

---

## ✨ Features

- Modern and responsive user interface
- Event-focused landing page
- Responsive design for desktop, tablet, and mobile devices
- Interactive frontend components
- Structured frontend and backend architecture
- Database integration using Prisma
- Server-side functionality
- Tailwind CSS based styling
- TypeScript development
- Vite-powered development environment
- Environment-based configuration
- Production-ready build configuration
